# Placement Portal

A full-stack web application developed to streamline campus placement activities by providing separate portals for Students, Companies, and Administrators. The system enables job postings, application management, company approval workflows, and placement tracking through a secure role-based architecture.

## Features

### Authentication
- Secure login using JWT authentication
- Role-based access for Admin, Company, and Student
- User registration and authorization

### Admin Module
- Dashboard with placement statistics
- Approve or reject company registrations
- Manage students and companies
- Monitor job postings
- Blacklist or deactivate users

### Company Module
- Company registration
- Create and manage job postings
- View student applications
- Update application status

### Student Module
- Student profile management
- Browse available jobs
- Apply for eligible positions
- Track application status

### Additional Features
- Redis caching for improved performance
- Asynchronous background tasks using Celery
- CSV export functionality
- RESTful API architecture
- Responsive user interface
